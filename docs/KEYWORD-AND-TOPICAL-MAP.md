# Topic and keyword map (14 Nov 2026)

Part of the SEO/AEO/GEO brief (see `docs/SEO-AEO-GEO.md`). Purpose: one destination page per topic, no two pages competing for the same query, and only topics the foundation actually works on.

## How to read this file
- **Search volumes: none are given.** No keyword tool data was available. Do not add numbers unless they come from Search Console (impressions) or a named keyword tool with a date.
- **Evidence** = what a live web search on 14 Nov 2026 showed ranking for that kind of query. These are observations, not rankings for this site.
- **Priority** is an estimate (ESTIMATED) based on fit with the foundation's real work and how crowded the results were.
- Swahili phrases are ESTIMATED candidates. Use them only after someone on the team confirms people actually say them that way, and only where the page carries matching Swahili wording approved by the foundation.

## Avoid (cannibalisation and accuracy)
- No separate location pages for towns or counties without documented activity there.
- No "best charity in Kenya" style pages.
- Stories target the person's journey; programme pages target the programme topic. Each story links up to its programme page.
- Don't target "children's home" or "orphanage" queries.
